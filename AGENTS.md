# AGENTS.md

This repo builds **Kakeibo** (a token budget diary for your coding agents). It reads local AI coding-agent session logs and breaks down where each session's tokens went (fixed overhead, resent history, tool output, retries, subagents, compaction), then flags what drained your quota. The CLI binary is **`kakeibo`** (crate `kakeibo`). The Homebrew formula is `kakeibo`, the menu bar cask is `kakeibo-bar` and the bundle id is `io.github.quiinthieu.kakeibo`. Names are set in `crates/kakeibo-core/src/product.rs` and `macos/Config/Product.xcconfig`. It's a Rust workspace (core, parse, index, report, and the `kakeibo` CLI/TUI) plus an optional thin Swift 6 menu bar app in `macos/`.

**The source of truth is [`PLAN.md`](./PLAN.md). Read §0 "Instructions for agents" before doing anything.**

Short version:
- Repo: `git@github.com:quiinthieu/kakeibo.git`. Branch from `main` as `task/TNN-slug`, one task per PR, Conventional Commits, squash-merge after CI passes (PLAN "Repository & workflow").
- Work on the lowest-numbered unchecked task in `PLAN.md` §10, and only that task. When its acceptance criteria pass, tick it and update `CHANGELOG.md`.
- Write tests first, against **synthetic** fixtures in `tests/fixtures/` (generated by `scripts/gen-fixtures/`). Never commit a real transcript. Use `TestEnv` (temp `HOME`); never touch the real `$HOME` in tests.
- `kakeibo-core` is pure: no I/O, no clock, no env. Agent logs and databases are opened read-only. Only `kakeibo-index` writes, inside Kakeibo's own cache/config dirs (plus `export --out`).
- Privacy: no network ever, and transcripts are never uploaded or stored. Parsers keep sizes, tool names and hashes, and drop text immediately. `scripts/lint-privacy.sh` enforces the no-network rule.
- Never invent numbers: prices, context windows and thresholds live in `data/*.toml` with a source URL and date (or empty placeholders). Label every figure `measured` or `estimated`. Formats marked *(verify)* get checked and recorded in `docs/formats/<agent>.md`.
- Commands: `cargo fmt --check`, `cargo clippy --workspace -- -D warnings`, `cargo test --workspace`, `cargo deny check`, `scripts/lint-privacy.sh`, `scripts/lint-fixtures.sh`, and for the menu bar app `xcodebuild -project macos/KakeiboBar.xcodeproj -scheme KakeiboBar test`.
